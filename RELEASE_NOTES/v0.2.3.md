# build-q v0.2.3

Rilis patch: uji manifest **satu namespace** sekaligus, dengan laporan yang bisa diekspor
ke Markdown/JSON. Dokumentasi: [E2E-MANIFEST.md §13](../E2E-MANIFEST.md).

## New

### 🧩 `bq --manifest-check <namespace>` (PR #19)

Pemeriksaan tahap Manifest `bq --e2e` (selector Deployment↔Service, `targetPort`,
Secret yang dirujuk, `regcred`, registrasi kustomization) untuk **semua Deployment** di folder
GitOps `<infra>/<namespace>/`. Read-only.

```bash
bq --manifest-check develop-qoin --export      # ringkasan + manifest-develop-qoin-<waktu>.md & .json
bq --manifest-check production-qoin --export-md laporan.md --export-json laporan.json
bq --manifest-check staging-ngenwal --gitops-branch staging
```

- Branch mengikuti ENV namespace (`develop-*`/`staging-*`/`sandbox-*` → branch sama, lainnya
  → `main`). Override dengan `--gitops-branch`, `--gitops-repo`, `--infra cce|k8s`.
- Cluster dipilih dari destination Application ArgoCD, lalu mapping `kube_cx`. Untuk namespace
  ambigu, dipakai cluster yang menjalankan Deployment folder tsb paling banyak.
- Secret dicek **sekali** per namespace (`kubectl get secrets -o name`, isi tidak dibaca);
  manifest dibaca paralel lewat GitHub API.
- Exit code: `0` semua OK, `1` ada FAIL, `2` ada SKIP — cocok untuk CI.
- **Laporan Markdown**: identitas scan, ringkasan, temuan per rule, daftar Deployment,
  detail + saran YAML. **JSON**: data yang sama untuk CI/dashboard.

### TUI & web

- TUI: `/manifest-check NAMESPACE [BRANCH]`; laporan `.md` + `.json` otomatis ke
  `~/.build-q/reports/`.
- Web: tombol **🧩 Namespace** / `/manifest-check NAMESPACE`, progres langsung, unduh
  `.md`/`.json`. Endpoint `POST /api/manifest-check` + SSE `/api/manifest-check/stream/<id>`,
  credential dari akun PocketBase pengguna.

## Fixed

- Secret config berakhiran env (`file-config-<app>-<env>`) kini dikenali. Sebelumnya
  Deployment yang me-mount Secret seperti ini (mis. aplikasi Rust di `develop-qoin`) keliru
  dilaporkan `missing_file_config_volume`. Bila Secret seperti itu ada di cluster tapi belum
  di-mount, saran YAML memakai nama yang sudah ada.
