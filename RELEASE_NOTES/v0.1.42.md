# build-q v0.1.42

Rilis ini memperkenalkan **`bq --serve PORT`** — Jev Agent Planner sebagai **web chat** di browser, zero new deps (stdlib HTTP + Server-Sent Events). Lengkap dengan M1-M6: core server, SSE streaming, token auth, UX polish, rate limit, dan katalog PocketBase.

## ✨ New

### `bq --serve 8888` — Jev Web Chat

Buka Jev di browser. Reuse 100% logic `tui.py` (pick_tool, extract_params, risk classification) — web layer hanya thin adapter.

```bash
bq --serve 8888
# → http://127.0.0.1:8888
```

Buka browser → tulis request natural → Jev suggest Top-3 tool → preview command → klik **Jalankan** → **streaming output real-time** via SSE.

#### 8 Routes

| Method | Path | Purpose |
|---|---|---|
| `GET` | `/` | Inline HTML+CSS+JS SPA (zero build step, zero asset file) |
| `GET` | `/api/health` | Version, provider, cache age, auth status |
| `GET` | `/api/catalog` | 33 tools, 2 providers, 17 patterns (ringkas) |
| `POST` | `/api/decide` | User msg → tool + Top-3 + params + preview |
| `POST` | `/api/execute` | Sync exec (untuk CI / curl) |
| `POST` | `/api/execute-stream` | Async spawn → `{job_id, stream_url}` |
| `GET` | `/api/stream/:id` | SSE `text/event-stream` line-by-line |
| `POST` | `/api/provider` | Switch provider runtime |

#### Security defaults

| Risk | Default |
|---|---|
| Remote exec | Bind `127.0.0.1` (localhost only); warning + sarankan token saat `0.0.0.0` |
| RISKY auto-run | Server guard: refuse execute kalau `risky && !confirm` |
| Credential leak | API key masked (`sk-xxx…xxx`) di `/api/health` |
| Shell injection | Allowlist: cmd harus diawali `bq ` atau `python3 -m ` |
| DoS flood | Rate limit 120 req/menit per IP untuk `/api/*` |
| Auth | Optional `--serve-token TOKEN` (Bearer header atau `?token=X` query untuk EventSource) |
| Audit | Append-only JSON log `~/.build-q/.serve-audit.log` |

#### CLI flags

```bash
bq --serve PORT                      # default: 127.0.0.1:PORT
bq --serve PORT --serve-host 0.0.0.0 # expose ke LAN (warning + token recommend)
bq --serve PORT --serve-token TOKEN  # Bearer required untuk /api/*
bq --serve PORT --serve-no-exec      # read-only / demo mode (decide only)
```

#### UI Features

- Top-3 kandidat cards dengan progress bar visual + highlight winner
- Param form auto-generate dari schema tool (text/choice)
- Live preview command update real-time saat edit parameter
- Execute button merah `[RISKY]` kalau destructive
- **Streaming output** via SSE, auto-scroll
- **Rerun button** per output panel (↻)
- **Export chat** button → download `jev-chat-{timestamp}.md`
- **Clear chat** button (dgn confirm)
- Provider switcher di header dropdown
- Token usage footer (hemat cost awareness)
- Dark mode GitHub-style, mobile-responsive
