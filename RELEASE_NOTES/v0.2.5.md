# build-q v0.2.5

Rilis patch: **mapping nodeSelector CCE per cluster × namespace** terpusat di collection
PocketBase baru **`nodepool`**, diselaraskan dengan node cluster nyata dan GitOps. Saran YAML
(`--manifest-init`, tahap Manifest `--e2e`/`--manifest-check`) dan template standar kini memakai
nodepool yang benar untuk setiap namespace. Detail: [E2E-MANIFEST.md §10](../E2E-MANIFEST.md),
[PRD-manifest.md](../PRD-manifest.md).

## New

### 🗂️ Collection PocketBase `nodepool` (PR #21, #22)

Satu record per cluster × namespace × role, nama unik `<cluster>/<namespace>/<role>`:

| Field | Isi |
|---|---|
| `name` | mis. `hw-pro-p/production-payout/front` |
| `kube_cx` | relasi ke cluster |
| `namespace`, `role` | `front` = manager/apigateway, `back` = module/worker |
| `label`, `value` | nodeSelector, mis. `cce.cloud.com/cce-nodepool` = `production-payout-nodepool-manager` |

24 record (baca: login, tulis: superuser). `kube_cx.nodepools` menyimpan inventaris pool yang
benar-benar ada di tiap cluster. Ubah lewat bagian `nodepool` di `scripts/build-q-seed.json` +
`bq --tui-sync`.

| Cluster | Namespace | Pool front / back |
|---|---|---|
| hw-dev | develop-qoin, develop-payout, develop-qoinhub, develop-saas | `develop-qoin-manager / -service` |
| hw-dev | develop-ngenwal | `develop-qoincash-manager / -service` |
| hw-dev | sandbox-qoin | `sandbox-qoin-manager / -service` |
| hw-pro-p | production-payout | `production-payout-nodepool-manager / -service` |
| hw-pro-q | production-qoin, staging-qoin | `production-nodepool-manager / -service` |
| hw-pro-u | production-ngenwal, production-saas, staging-ngenwal | `production-ue-nodepool-manager / -service` |

## Improved

- **Saran YAML memakai nodeSelector per namespace × cluster** dari collection `nodepool`;
  params rule `nodepool_mismatch_cce` tetap sebagai cadangan. Collection mendukung label selain
  `cce-nodepool` bila suatu cluster membutuhkannya.
- **`--manifest-template`** membaca branch tempat namespace di-deploy (develop/staging/sandbox
  atau `main`) — sebelumnya `main`, sehingga folder develop yang basi menghasilkan pool production.
  nodeSelector kini termasuk kriteria standar template. Template aktif: 23 (develop-qoin,
  develop-payout, develop-qoinhub, develop-saas, sandbox-qoin kini punya template).
- **`--tui-sync`** mendukung collection `nodepool` (relasi `kube_cx` ditulis dengan nama cluster).
- Cache `~/.build-q/.kube-cx-cache.json` naik ke format v3 (otomatis diambil ulang).

## Fixed

- **production-payout memakai nama pool presisi**, bukan `nodetype: front|back`. Di hw-pro-p,
  `nodetype=front` juga menempel di pool `monitoring` dan `workflow`; terbukti 4 pod manager
  berjalan di pool monitoring, 1 di workflow, dan 2 di pool service.
- **Mapping namespace ↔ cluster** hanya untuk namespace yang benar-benar ada di cluster
  (dicek `kubectl get ns`): `develop-payout` hanya di hw-dev (record lama di hw-pro-p dihapus);
  folder GitOps yang tidak di-deploy (`staging-payout`) tidak dicatat.

## Catatan

Manifest `cce/production-payout/` di repo GitOps masih memakai `nodetype: front|back`;
perbaikannya (ganti ke `cce-nodepool` presisi) adalah perubahan di repo GitOps, terpisah dari rilis ini.
