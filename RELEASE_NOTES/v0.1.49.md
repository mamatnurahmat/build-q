# build-q v0.1.49

Rilis ini menambah dua perintah di `bq auth` untuk **mengambil credential milik sendiri**
dari PocketBase devops, lalu menyimpannya ke lokasi yang Anda tentukan.

## New

### `bq auth list` — daftar credential yang boleh diakses

```bash
bq auth list
```

Menampilkan `key`, `scope`, `env`, `type`, dan `owner`, **tanpa isi**. Daftarnya mengikuti
aturan akses server: credential milik sendiri, atau semua credential bila role `admin`.

### `bq auth get <KEY>` — isi credential ke stdout

```bash
bq auth get KUBECONFIG_READONLY_HW_B64 > ~/.kube/config-readonly-hw
bq auth get GITHUB_TOKEN --scope github --env all     # pilih scope/env bila key ambigu
bq auth get SOME_B64 --raw > file.b64                 # tanpa decode base64
```

- **Hanya isi credential yang ditulis ke stdout.** Pesan dan error masuk ke stderr, sehingga
  `> lokasi` menghasilkan file yang bersih.
- **Decode base64 otomatis** untuk key berakhiran `_B64` atau ber-tag `base64`. `--raw`
  mematikannya, dan value yang bukan base64 valid menghasilkan error yang jelas.
- **Key ambigu:** bila key yang sama ada di beberapa scope/env, `bq` menampilkan pilihan
  `--scope` / `--env`.
- **Diambil langsung dari server** dengan token `bq auth login` (bukan dari cache), sehingga
  aturan owner selalu berlaku.
- **Validasi input:** nama key/scope/env divalidasi (`[A-Za-z0-9_.-]`) agar tidak bisa
  menyisipkan filter.
- Bila stdout adalah terminal, muncul peringatan bahwa isi credential tampil di layar.
- Exit code: `0` sukses, `1` tidak ditemukan / bukan milik sendiri / belum login.
