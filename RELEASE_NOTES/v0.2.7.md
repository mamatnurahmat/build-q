# build-q v0.2.7

Rilis patch: **`bq bin`**, sinkronisasi skrip tool bersama (`~/.build-q/bin`) dengan collection
PocketBase `bq_bin`. Fase 1: hanya memindahkan berkas, `bq` tidak menjalankan isinya.

## New

### 🧰 `bq bin`

- `bq bin ls`: daftar tool di PocketBase, dengan kind, ukuran, sha, versi, dan apakah ada di lokal.
- `bq bin check [--json]`: bandingkan lokal dengan PocketBase. Tidak mengubah berkas. Exit 0 bila
  semua cocok, 1 bila ada beda, 2 bila PocketBase tidak terjangkau. Memberi peringatan untuk nama
  yang sama dengan perintah sistem.
- `bq bin pull <nama> | --all [--yes]`: unduh tool yang berbeda. Menampilkan diff, meminta
  konfirmasi (kecuali `--yes`), membuat backup di `~/.build-q/bin/.bak/`, lalu mengganti berkas
  secara atomik. Sha256 yang tidak cocok membatalkan semua penggantian (exit 122).
- `bq bin push <file> [--mode 0644|0755] [--kind bash|python|binary] [--version] [--notes] [--email] [--yes]`:
  unggah tool. Hanya superuser. Ditolak bila ada pola rahasia (nilai tidak dicetak, hanya label dan
  nomor baris).
- `--pb-url` global untuk tes lokal (mis. `http://127.0.0.1:8193`).

### 🗄️ Collection `bq_bin` (PocketBase)

- Migrasi `1793000000_bq_bin.js` dan `1793000001_bq_bin_protected.js`.
- Field: name (unik, pola huruf kecil), file (maks 512 KB, protected), sha256, size, mode, kind,
  version, notes, created, updated.
- Baca dan unduh hanya untuk pengguna login. Tulis hanya superuser.
- Hook menghitung ulang sha256 dan size dari isi berkas. Klaim yang tidak cocok ditolak (400).
  Pada update, record dan berkas lama dikembalikan.

## Keamanan

- Nama tidak boleh sama dengan perintah sistem: daftar tetap, isi folder sistem (`/bin`, `/usr/bin`,
  `/usr/sbin`, `/sbin`), dan isi setiap folder di PATH. Folder `bin` bq sendiri dikecualikan.
  Berlaku di push dan pull.
- URL PocketBase harus https, kecuali 127.0.0.1 dan localhost. Berlaku untuk `--pb-url`,
  `PB_API_URL`, dan login password.
- `.bak` dan `.tmp` yang berupa symlink ditolak.
- Pemindai push mencakup token GitHub, GitLab, Slack, Stripe, Google (AIza), Docker Hub, AWS, kunci
  privat, JWT, kredensial di URL, basic auth, dan flag `--password`/`--token`/`--secret`. Ini pagar,
  bukan jaminan. Referensi shell (`$...`) dan placeholder (`<...>`) tidak dihitung.
- Tidak ada tanda tangan pada tool di fase 1. Superuser yang mengunggah menentukan isinya.

## Catatan

- Collection `bq_bin` harus sudah ada di PocketBase. Sebelum itu `bq bin` gagal dengan pesan
  PocketBase. Pembuatannya di produksi memerlukan izin terpisah.
- `bq` lain tidak berubah. Perintah yang sudah ada berjalan seperti sebelumnya.
