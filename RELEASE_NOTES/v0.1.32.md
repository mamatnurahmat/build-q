# build-q v0.1.32

Rilis ini menambah tiga perintah native baru dan memperbaiki UX beberapa tools existing.

## ✨ New

### `bq --doctor` — preflight tools & credentials
Cek kesiapan environment sebelum jalankan `bq` build / `--pr-fix` / `--bootstrap-k8s`:
- Tools esensial: git, docker, docker buildx (+ opsional: kubectl, gh)
- Config `~/.build-q/.env`: REGISTRY_URL, GITHUB_ORG, DOCKERHUB_ORG
- GitHub credentials: GITHUB_TOKEN valid (GET /user) atau `gh auth status` bila `GH_CLI=true`
- Docker login (`~/.docker/config.json`)
- Buildx builder exist
- kubectl context reachable

**Interactive fixer**: bila ada blocker/warning yang fixable (config kosong, token invalid, builder belum ada, dll), doctor prompt `Fix now? [y/N]` per item. Non-TTY (CI) → skip silent.

```bash
bq --doctor
# Contoh fixer flow (TTY):
#   Fix 'GITHUB_TOKEN' — paste token / gh auth login? [y/N]:
```

### `bq --set-image` — hot-patch Deployment (imperative)
Menggantikan script bash eksternal `set-image`. Native Python: `kubectl set image` + `kubectl rollout status --watch`.

```bash
bq --set-image <ns> <deployment> <image> [container]

# Bila <image> plain tag (tanpa `/`), otomatis:
#   <REGISTRY_URL>/<deployment>:<tag>
bq --set-image production-qoin plus-be-example v1.2.3
```

### `bq --gitops-set-image` — update image di GitOps (declarative)
Menggantikan script bash eksternal `gitops-set-image`. Native Python dengan preflight lengkap:
1. Validasi format image + path `.yaml`
2. Cek file exist di GitHub (native REST, no `gh` dep)
3. Cek image ready di Docker Hub (Registry v2 + Hub API fallback)
4. Duplikasi (image di file = arg → skip)
5. Clone shallow → regex replace `image:` → commit → push

```bash
bq --gitops-set-image <gitops-repo> <branch> <path.yaml> <image_full>

bq --gitops-set-image Qoin-Digital-Indonesia/gitops main \
  cce/production-qoin/plus-be-example_deployment.yaml \
  loyaltolpi/plus-be-example:v1.2.3
```

## 🔧 Improvements

### `bq --cicd-webhook` — panduan web fallback + auto-open browser
Ketika CLI mode gagal (bukan admin repo, HMAC tak bisa diambil, POST /hooks 403/404), sekarang:
- Print 8-step panduan setup manual via GitHub UI (Payload URL, Content type, Secret, Events, dll)
- Prompt `Buka <URL> di browser sekarang? [y/N]` (TTY-only) → `webbrowser.open()`
- URL langsung: `https://github.com/<owner>/<repo>/settings/hooks/new`

Applies ke `run_cicd_webhook_check` (dipanggil `bq --cicd-webhook`) dan `run_cicd_webhook_setup` (dipanggil `bq --pr-fix`).

### Rollout suggestion pasca-build
Suggestion sekarang emit `bq --set-image` dan `bq --gitops-set-image` (native), bukan script bash eksternal:

```
📤 Rollout suggestions (copy-paste ke terminal):

   # 1) Hot-patch cluster (imperative, cepat)
   bq --set-image staging-qoin plus-be-example v1.2.3

   # 2) Via GitOps (declarative, ArgoCD sync)
   bq --gitops-set-image Qoin-Digital-Indonesia/gitops main \
     cce/staging-qoin/plus-be-example_deployment.yaml \
     loyaltolpi/plus-be-example:v1.2.3
```
