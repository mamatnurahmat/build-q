# build-q v0.2.8

Rilis patch: **mode lokal tanpa PocketBase** dan **jalur GitHub native dengan fallback SSH**.
Konfigurasi default untuk instalasi baru kini berpusat pada `~/.build-q/.env`.

## New

### 🏠 Mode lokal (`BUILD_Q_DISABLE_PB_API=true`)

- Saat aktif, `bq` tidak menyentuh PocketBase: gate login dilewati, secret dibaca dari `.env`,
  dan tidak ada permintaan ke PB API.
- `bq --doctor` tidak lagi menganggap login bq sebagai blocker di mode lokal.
- Fallback ke collection PB `repo` pada `--bootstrap-k8s` dilewati di mode lokal.
- Template `.env` baru (`bq --init`) default ke mode lokal: `BUILD_Q_DISABLE_PB_API=true`,
  `PB_API=false`, `GH_CLI=false`. `PB_API_USER` / `PB_API_PASS` (superuser lama) dihapus dari template.

### 🔁 Fallback SSH untuk GitHub (jalur native)

- Bila token REST ditolak (HTTP 401/403) atau kosong, pengambilan commit dan file dialihkan ke
  SSH key user (`ssh_get_commit`, `ssh_get_file`). Tidak lagi langsung gagal.

## Changed

- `builder`, `cloud_build`, `cli`, `e2e`, dan `pb_auth` menyesuaikan jalur mode lokal dan
  menyediakan hasil image (`out["image"]`) untuk `--json`.
- `--json` mengalihkan stdout ke stderr agar output JSON bersih untuk `$(bq ... --json | jq ...)`.

## Upgrade

- Instalasi lama tidak berubah. Untuk memakai mode lokal, set `BUILD_Q_DISABLE_PB_API=true`
  dan hapus `PB_API_USER` / `PB_API_PASS` dari `~/.build-q/.env`.
- Pastikan `GITHUB_TOKEN` valid (`bq --doctor`), atau biarkan fallback SSH yang dipakai.
