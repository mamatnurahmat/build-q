# build-q v0.1.43

Rilis ini memperkenalkan **`bq --fix-dockerfile` v2** — Dockerfile scanner komprehensif dengan **Jev System One verdict, auto-fix engine, dan 3 mode operasi** (local, remote, PR-fix). Ekspansi dari 4 rule menjadi **24 rule** across 4 kategori, dilengkapi **120 test** dan PRD lengkap.

## New

### `bq --fix-dockerfile` v2 — Dockerfile Scanner + Jev-Approved Auto-Fix

Scan Dockerfile untuk **24 issue umum** (build failure, security risk, image bloat, compliance), dengan Jev System One memberikan severity synthesis, fix approval, dan priority ranking.

#### 3 Mode Operasi

```bash
# 1. LOCAL — scan + auto-fix file lokal
bq --fix-dockerfile
bq --fix-dockerfile docker/Dockerfile

# 2. REMOTE — scan via GitHub API tanpa clone (read-only)
bq --fix-dockerfile Dockerfile \
  --remote-repo Qoin-Digital-Indonesia/pay-be-topup-manager \
  --remote-branch staging

# 3. PR-FIX — scan remote, jika ada error → clone → fix → buat PR
bq --fix-dockerfile Dockerfile \
  --remote-repo ngenwal-be-snapconvert-module \
  --remote-branch master \
  --pr-fix-dockerfile
```

#### 24 Rules (4 Kategori)

| Kategori | Error | Warning | Info | Total |
|----------|-------|---------|------|-------|
| **build** | 7 | 4 | 0 | 11 |
| **security** | 0 | 3 | 0 | 3 |
| **performance** | 0 | 5 | 2 | 7 |
| **compliance** | 0 | 0 | 3 | 3 |

**Deteksi**: 17 regex-based + 7 structural checks (parse instruction ordering).

Top rules dari real-world scanning 100+ repo Qoin:

| Rule | Severity | Deskripsi |
|------|----------|-----------|
| `legacy-github-secrets` | error | Secret `id=github_token` legacy, harus netrc |
| `env-before-from` | error | Instruksi sebelum FROM — syntax invalid |
| `registry-literal-placeholder` | error | FROM `REGISTRY01/PROJECT` template unreplaced |
| `deprecated-maintainer` | error | MAINTAINER deprecated → LABEL |
| `private-repo-bitbucket` | error | Bitbucket references deprecated → GitHub |
| `missing-user` | warning | Container run root — security risk |
| `copy-all-before-deps` | warning | COPY . . sebelum go mod download — cache bust |
| `apt-get-no-clean` | warning | apt-get tanpa cleanup — 50-200MB+ bloat |
| `missing-multistage` | info | Single-stage Go/dotnet build — image 1GB+ |

#### 9 Auto-Fix Rules

| Rule | Fix Action |
|------|-----------|
| `deprecated-maintainer` | `MAINTAINER x` → `LABEL maintainer="x"` |
| `env-legacy-syntax` | `ENV KEY value` → `ENV KEY=value` |
| `from-as-lowercase` | `as` → `AS` di FROM |
| `arg-github-token-legacy` | Hapus `ARG GITHUB_*` lines |
| `netrc-secret-wrong-target` | Tambah `target=/root/.netrc` |
| `workdir-commented-out` | Uncomment `#WORKDIR /app` |
| `add-instead-of-copy` | `ADD src dest` → `COPY src dest` |
| `pip-no-cache` | Tambah `--no-cache-dir` ke pip install |
| `legacy-github-secrets` | Report (needs netrc migration) |

#### Jev System One Integration

Satu HTTP call per file (~$0.0002, ~936 input tokens):

| Question | Type | Fungsi |
|----------|------|--------|
| `overall_severity` | choice | Synthesis: clean / warn / critical |
| `safe_to_autofix` | noul | Probability aman auto-fix (safety gate >= 50%) |
| `fix_priority` | choice | Prioritas: security / build / performance / compliance |

**Safety gate**: jika Jev `safe_to_autofix < 50%`, auto-fix dilewati. Jev fail → deterministic checks tetap jalan (fail-safe).

#### Remote Mode (No Clone)

Scan Dockerfile langsung dari GitHub API — tanpa clone, tanpa disk:

```bash
bq --fix-dockerfile Dockerfile \
  --remote-repo pay-be-topup-manager \
  --remote-branch staging

# Scan semua Dockerfile di repo (recursive tree listing)
bq --fix-dockerfile . --remote-repo owner/repo --remote-branch main
```

Pakai `GET /repos/{owner}/{repo}/contents/{path}?ref={ref}` (raw mode) untuk fetch file, dan `GET /repos/{owner}/{repo}/git/trees/{ref}?recursive=1` untuk directory listing.

#### PR-Fix Mode

Scan remote → jika ada **error-level** findings → clone → auto-fix → buat PR:

```bash
bq --fix-dockerfile Dockerfile \
  --remote-repo pay-be-topup-manager \
  --remote-branch staging \
  --pr-fix-dockerfile
```

**Skip PR** jika:
- Dockerfile clean (0 findings)
- Hanya warning/info (tidak ada error)
- Error tapi tidak ada rule auto-fixable
- Auto-fix tidak menghasilkan diff

PR body lengkap: fixes applied, remaining issues, Jev verdict.

#### Export CSV + Markdown

```bash
bq --fix-dockerfile Dockerfile --export-csv report.csv --export-md report.md
bq --fix-dockerfile Dockerfile --remote-repo owner/repo --remote-branch main \
  --export-csv scan.csv --export-md scan.md
```

#### CLI Flags Lengkap

```bash
bq --fix-dockerfile [PATH]              # scan + auto-fix (default: ./Dockerfile)
bq --fix-dockerfile --scan-only         # scan only, tanpa modifikasi
bq --fix-dockerfile --no-autofix        # disable auto-fix
bq --fix-dockerfile --no-jev            # deterministic only (offline, faster)
bq --fix-dockerfile --remote-repo REPO  # remote scan via GitHub API
bq --fix-dockerfile --remote-branch REF # branch/tag/SHA (default: main)
bq --fix-dockerfile --pr-fix-dockerfile # remote → clone → fix → PR
bq --fix-dockerfile --export-csv PATH   # CSV audit trail
bq --fix-dockerfile --export-md PATH    # Markdown report
```
