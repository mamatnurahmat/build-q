# build-q v0.1.41

Rilis ini memperkenalkan **`bq --anomaly-scan`** — scanner anomali config Kubernetes dengan **hybrid deterministic + Jev System One verdict**. Mendukung single-file / seluruh namespace folder, dan export CSV / Markdown.

## ✨ New

### `bq --anomaly-scan <PATH>` — K8s manifest anomaly scanner

Scan 1 file YAML ATAU seluruh direktori gitops untuk anomali config (Deployment / Secret). Hybrid approach:

- **10 deterministic checks** di Python (fast, akurat, zero LLM cost)
- **Jev verdict call** sekali per resource untuk overall severity + prod_ready score
- **Exit code semantik**: `0=safe`, `1=warn`, `2=critical` — siap jadi CI gate di repo gitops

#### Mode dinamis — file atau direktori

```bash
# Single file
bq --anomaly-scan cce/production-qoin/pay-be-topup_deployment.yaml

# Seluruh namespace (glob default *_deployment.yaml)
bq --anomaly-scan cce/production-ngenwal

# Custom glob
bq --anomaly-scan cce/production-qoin --anomaly-glob '*.yaml'
```

#### 10 Deterministic Rules

Diambil dari pengalaman real Qoin (skill `k8s-manifest-fix`, `pdb-production-standards`, `file-config-setup`, `argocd-sops-troubleshoot`):

| Rule | Severity | Resource |
|---|---|---|
| `prod_replicas_lt_2` | critical | Deployment (prod only) |
| `missing_image_pullsecret` | critical | Deployment |
| `image_latest_tag` | critical | Deployment |
| `env_var_hardcoded_credential` | critical | Deployment |
| `privileged_container` | critical | Deployment |
| `host_network_true` | critical | Deployment |
| `secret_plaintext_committed` | critical | Secret (SOPS/SealedSecret aware) |
| `missing_liveness_probe` | warn | Deployment |
| `missing_readiness_probe` | warn | Deployment |
| `missing_resources_limits` | warn | Deployment |

Katalog lengkap (46 rules untuk pengembangan ke depan) ada di [`scripts/anomaly-rules-seed.json`](../scripts/anomaly-rules-seed.json).

#### Jev System One Verdict (opt-in)

Default: Jev dipanggil **hanya untuk resource yang punya findings** (hemat token). Setiap call ~1000 token in / 60 out — ekonomis.

```bash
# Deterministic only (offline, zero LLM cost)
bq --anomaly-scan <path> --no-jev
```

Jev memberikan:
- `overall_severity`: `safe` / `warn` / `critical` + `confidence`
- `prod_ready`: noul probability 0.0–1.0

#### Export CSV + Markdown

```bash
# Export keduanya sekaligus
bq --anomaly-scan cce/production-ngenwal \
   --export-csv report.csv \
   --export-md report.md
```

**CSV**: flat 1 row per finding — kolom `file, resource_kind, namespace, severity, rule_name, category, message, fix_hint, jev_overall, jev_confidence, jev_prod_ready`. Siap buka di Excel / Sheets.

**Markdown**: summary agregat (severity count + top rules + per-kategori) + detail per resource (tabel findings + Jev verdict). Siap render di GitHub / VSCode.
